# 竞赛筛选与信息提取对照

日期：2026-10-30。模型：GPT-6 Luna；详情提取使用 high，列表初筛使用 Decisions API。

在本次15条真实公告中，新流程能读取两条旧解析器不支持的意大利竞赛页面，并排除一条旧规则保留的已授标公告。官网和项目位置的覆盖有所改善；截止日期和合同金额的覆盖数没有净增。仍有专项设计和非建筑项目进入待核实，奖金识别的改善尚未得到本批样本证明。

## 对照范围

样本为6条 TED 公告、6条 BOAMP 公告和3条意大利 CNAPPC 竞赛页面。前两组来自公开接口的首批候选，后一组为两个现行设计竞赛与一个作品评奖。样本不是随机抽样，也没有覆盖全部政府网站。

旧流程采用仓库原有来源解析器、来源相关性判断与关键词偏好。新流程在相同公告上先进行宽松列表判断，再读取可访问的详情并提取信息。详情读取的扩大也是新旧结果差异的一部分，因此不能把所有改善都归因于模型判断能力。

## 已核对的改善与边界

- 帕多瓦学校竞赛：旧通用解析器只接受采集器生成的 JSON，不能直接读取该 HTML 页面。新流程提取了项目题名和 Via Guido Reni 项目位置。页面的“下一项期限”对应澄清事项，未被写成提交截止日期。日程仍需查看更新后的竞赛文件。
- 福贾城市更新竞赛：提取了项目所涉街道和2026-11-27的第一阶段提交期限。项目街道没有被网页底部的采购方办公地址替代。
- 德国住宅改造：提取了 Wiesengrund 3–5 的项目位置、2026-11-27的参与申请截止日期，以及920,000欧元未税估算价值。该金额是合同价值，不是奖金。
- 捷克街区更新：旧规则保留；新流程读到结果和授标信息后排除。
- 波兰医院项目：保留了以 PLN 计价的金额原文，没有写入欧元金额字段。设计施工总承包是否适合当前团队，仍需资格复核。
- 德国学校项目的主体是结构设计。模型给出“推荐进一步查看”，同时写明需核实专业能力与合作需求；这不能视为已经符合建筑师团队的投标资格。
- 机场专项、数字巴士等仍有主题边界问题。其中数字巴士存在设计用语，但不一定涉及建筑设计。当前按宽松初筛保留待核实，不能据此宣称已可靠排除全部无关项目。
- 本批最终结果没有得到可核实的奖金字段。部分参赛条件和奖金在链接文档内，本次流程未读取 PDF，因此不计算奖金提取准确率。

## 固定案例组的字段覆盖

对医院设计施工、学校结构设计、住宅改造及两个意大利设计竞赛这5个潜在设计机会，按字段是否有值统计如下。这是覆盖数，不是准确率，也不是随机抽样。

| 字段 | 旧流程有值 | AI流程有值 |
| --- | --- | --- |
| 官方页面 | 3/5 | 5/5 |
| 项目位置 | 0/5 | 4/5 |
| 截止日期 | 3/5 | 3/5 |
| 欧元合同金额 | 1/5 | 1/5 |
| 奖金 | 0/5 | 0/5 |

日期提取有得有失，不能仅凭新增福贾提交期限就宣称整体改善。当前改善主要体现在异构页面可读性、官网和项目位置覆盖；金额和奖金识别仍需扩大样本验证。

## 成本

最终两阶段组合的估算费用为 $0.024414，其中列表初筛约 $0.001018，9条详情提取约 $0.023396。费用按 API 返回的 token 用量与标准价格估算，未计缓存折扣。实际账单以 OpenAI 平台为准。

包含调试、失败与复测的本次本地记录合计约 $0.089821 已知估算费用；另有一次网络结果不明，保守保留 $0.008313 的费用额度。初期两次极小的 Decisions 联通探针另约 $0.000034。没有用失败记录充当成功结果。

每天1美元的成本目标在本批样本规模下可行。不能据此保证每日可处理的公告数量或完成时间，长页面、附件和网络失败会改变用量及耗时。

## 当前判定标准

候选记录至少需要有原文支持的题名。缺少价格、地址或资格信息不会导致整条作废。不支持的单个字段留空；不支持的判断依据使结果变为待核实。只有有明确依据的排除才影响发现列表。推荐表示值得进一步查看，不表示已核实资格或保证可报名。

用户偏好保存在 `config/ai-screening.md` 和 `config/filters.yml`。来源查询范围、分页和抓取上限仍由采集器控制；TED 的查询范围可通过来源配置的 `search_query` 修改。任意列表的自动发现、登录和验证码处理，以及 PDF 内容识别未在本轮实现。
