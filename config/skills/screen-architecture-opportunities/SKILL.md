# 筛选设计机会

为执业建筑师、建筑事务所或含建筑师的联合体寻找仍可参与、能够带来实际设计委托的机会。结合调用方提供的地区、费用和项目偏好排序。

## 判断方法

1. **看交付内容。** 识别本次采购要解决的主要问题和交付成果，判断是否包含建筑、城市或景观的整体空间与使用方案设计。项目名称、采购方和分类代码只能提供线索；程序预先生成的分类提示不作为公告原文，不能推翻明确的采购内容。综合委托有明确的目标设计工作就保留；仅为建设提供技术支持、管理、供货或施工，不等于空间设计委托。
2. **看当前机会。** 判断公告是否仍开放新的参与途径，以及设计与后续委托或实施的关系。历史结果、既有合同变更和作品展示没有新的设计委托时排除。依据当前阶段的日期判断，不把公告发布日期或澄清日期当作提交期限。
3. **区分不匹配与未知。** 已知交付内容足以表明不匹配时，其他信息缺失不改变排除判断，不推测尚未公告的目标设计工作。目标设计明确时，缺少费用、地址或资格细节不构成排除理由。只有未知信息会改变匹配或参与判断时才待核实，并指出需核实什么。国家和语言优先级不作为准入限制。

## 给出判断

- **推荐**：目标设计与参与机会明确，值得进一步查看。
- **排除**：已读取的材料明确表明不符合目标。
- **待核实**：缺少会改变匹配或参与判断的关键证据。

只用实际读取的材料支持结论，未知字段留空。分别识别项目地点与联系地址、设计报酬与建设投资等不同含义。推荐不代表已经核实投标资格。

## 提取参与信息

同一次阅读中，保留影响参与决策的明确条款：各阶段的日期与时区、费用与报酬、资格与联合体要求、设计范围与交付成果、提交方式与文件入口。按时间、商务、资格、工作范围、提交五类合并，引用简短的原文。分清报名、提问与提交期限；分清设计合同、建设投资、奖金与保证金。没有说明的内容留空，不根据国家或惯例补全。

项目地点分别保留可证实的详细地址、城市、行政区和国家，供程序按精度逐级查询地图。不要把采购人或代理机构地址当作项目地点，不生成经纬度。

## 维护

出现误判时，先检查输入是否包含判断所需的证据，再修正共同判断依据，并用未参与调优的跨国样本复测。优先概括规律，仅保留有复测证据支持的必要例外。
